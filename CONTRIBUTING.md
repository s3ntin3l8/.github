# Contributing to s3ntin3l8's Projects

First off, thank you for considering contributing! It's people like you who make these tools better for everyone.

## Getting Started

1. **Check for Issues:** Before starting, check the issues tab to see if the feature/bug is already being worked on.
2. **Open an Issue:** If it's a major change, please open an issue first to discuss the approach.

## Development Workflow

1. **Fork & Clone:** Fork the repository and clone it locally.
2. **Create a Branch:** Use a descriptive branch name (e.g., `feat/add-new-collector` or `fix/broken-logic`).
3. **Set Up Environment:** Most projects use `make install` or `pip install -r requirements-dev.txt`.
4. **Write Code:** Follow the existing style (use `ruff` and `mypy` if applicable).
5. **Add Tests:** Contributions without tests are unlikely to be merged.
6. **Lint & Test:** Ensure everything passes locally before pushing.

## Pull Request Process

1. **Conventional Commits:** Please use [Conventional Commits](https://www.conventionalcommits.org/) for your commit messages.
2. **Template:** Fill out the PR template completely.
3. **Review:** One of the maintainers will review your PR as soon as possible.

## Security

Please refer to our [Security Policy](SECURITY.md) for reporting vulnerabilities.
